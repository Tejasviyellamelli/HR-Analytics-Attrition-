# HR-Analytics-Attrition-
## HR Attrition Analysis Dashboard
This project analyzes employee attrition patterns using Power BI.  
It highlights key drivers (salary, tenure, overtime), workforce demographics, and provides actionable HR recommendations.

### Key Insights
- Attrition rate: 16.08% (238 inactive employees)
- Highest turnover among 18–25 age group and low salary slabs
- Sales Representatives and HR staff face highest attrition risk
- Career progression opportunities reduce attrition

### Tools Used
- Power BI (data modeling, DAX, visualization)
- IBM HR Analytics dataset
