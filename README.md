# HR Attrition Analysis Dashboard (Power BI)

## Objective
Built an interactive dashboard to analyze employee attrition patterns and provide actionable insights for HR decision-making.

## Dataset
IBM HR Analytics Employee Attrition dataset (Kaggle, 1,480 records).

## Tools & Skills
- Power BI (data modeling, DAX, visualization)
- Analytical storytelling with multi-page dashboards

## Dashboard Features
- Attrition Overview: KPIs on attrition %, tenure, salary distribution
- Attrition Drivers: Salary slabs, overtime, job level, promotion gap
- Workforce Profile: Attrition by age, marital status, gender, job role, department
- Recommendations: Targeted HR actions to reduce turnover

## Key Insights
- Attrition rate: **16.08%** (238 inactive employees)
- Highest turnover among **18–25 age group** and **low salary slabs**
- **Sales Representatives & HR staff** face highest attrition risk
- **Overtime workers (25.28%)** more likely to leave

## Impact
Identified high-risk groups and provided actionable strategies for HR managers to improve retention.
